# 12-Hour Inpatient Roster

Mobile web app for building 12-hour Day/Night nursing rosters (men's & women's wards).

- Live: https://aliutaif.github.io/roster/
- Fixed Day/Night teams, monthly hours target, minimum cover per shift, overtime/cross-cover gap filling
- Tap-to-edit cells, multiple roster options, problems checker, CSV/PDF export, backup/restore
- Works offline; add to iPhone Home Screen from Safari

Staff names are not stored in this repo — load your private staff list via **Share / Export → Restore from backup**.
